# causas

Case management and tracking for a lawyer or a law firm.
Built with Vite, React 19 and strict TypeScript. Data lives in `localStorage`.
The UI is in Spanish; code and docs are in English.

Requires Node 22 and pnpm.

- `pnpm install` — install dependencies.
- `pnpm dev` — start the dev server.
- `pnpm check` — run lint, typecheck and tests.
